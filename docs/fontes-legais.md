# Fontes legais lidas

Regra deste arquivo: só entra no motor um valor que foi **lido em texto oficial baixado com `curl -sSL -m 30 -A 'Mozilla/5.0'`**, nunca resumo de busca nem memória. Data de acesso de tudo abaixo: **2026-11-21**. O que não foi baixado ou lido está na segunda tabela e **não** entrou.

Confiança: "alta" só se o texto oficial integral da norma foi lido; "média" quando a página oficial foi lida mas não é a norma integral (ou a norma é consolidada por terceiro, ou há ponto não lido). Toda regra segue com `requiresValidation: true` até a conferência humana (#98), e o campo `confidence` do motor permanece `medium`.

## Como regerar

Os dados das regras nascem em `src/engine/data/*.ts`. Depois de mudar, rode `UPDATE_RULES=1 UPDATE_GOLDEN=1 npx vitest run src/engine/__tests__/rules-export.test.ts src/engine/__tests__/golden-export.test.ts` e confira o diff de `api/app/engine/data/rules.json`, `rules.manifest.json` e `api/tests/golden/cases.json` (ver `docs/backend-fastapi.md`).
